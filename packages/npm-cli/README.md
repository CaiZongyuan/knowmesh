# KnowMesh

KnowMesh is a local-first knowledge infrastructure project built around a Rust
CLI, Markdown and YAML source files, SQLite search and graph indexes, and
reviewed knowledge proposals.

## Release Status

`0.0.0-bootstrap.0` initializes the project's npm distribution. It contains
project metadata and the MIT license. It does not include a CLI executable,
download a backend binary, or provide the planned v0.1 functionality.

This release uses the `bootstrap` distribution tag. Usable CLI releases will
follow the native backend release and install the matching precompiled binary.
The optional Web application will be distributed separately.

Source and development status: <https://github.com/CaiZongyuan/knowmesh>.

# P29 三类 Harness 的薄 Loader 安装器

## Parent

[并行实施规格](../spec.md)；原始需求 [#32](https://github.com/CaiZongyuan/knowmesh/issues/32)。

## What to build

为 Claude Code、Codex 和 generic 提供可预览、可重复执行的 Loader 安装流程。Loader 从当前 binary 选择并读取最小相关 Skill，用户可以核对写入路径和内容后再安装。

## Acceptance criteria

- [ ] install-loader 支持 claude-code、codex、generic；只使用有依据的目标目录规则，无法确定目标时引导用户显式导出，不猜测目录。
- [ ] 默认使用 project scope；user scope 需要显式指定，实际写入需要确认，dry-run 返回精确目标路径与内容 hash 且不创建目录或文件。
- [ ] Loader 仅包含资源发现、选择、读取、遵循当前 Skill 和不可信来源处理规则，不复制业务实现或整套内嵌文档。
- [ ] 相同内容重复安装为无变化；已有不同内容保持不变，只有同时提供 force 与 yes 才允许替换，写入失败返回可诊断错误。
- [ ] 路径含空格、不可写目录、目标冲突和异常路径均有安装器集成 fixture；临时 user scope 测试不触碰真实个人 Harness 配置。
- [ ] 安装后 Loader 引用当前可发现的 binary 命令；更换兼容后端版本时无需复制旧版 Skill，generic 显式导出流程有完整可执行例子。

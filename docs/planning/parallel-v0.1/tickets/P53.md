# P53 十个真实问题的人工 Answer 与刷新评测

## Parent

[并行实施规格](../spec.md)；原始需求 [#42](https://github.com/CaiZongyuan/knowmesh/issues/42)。

## What to build

用至少 10 个真实 Virtual Cell 研究问题完成 Ask、Synthesis 保存与来源刷新 dogfooding。由人工逐句核对事实支持、冲突和知识缺口，并保留初次回答与更新后的完整历史。

## Acceptance criteria

- [ ] 至少 10 个问题来自 P01 的可追溯研究任务，记录人工审核的问题版本、研究意图与判断依据；人工评审或真实模型未就绪时明确保持相关验收未完成。
- [ ] 实际 Ask 执行记录代码、材料、模型、prompt/schema 版本、Run、bundle、回答、token 用量与成本；通过显式审核保存 Synthesis，结果可回到实际输入模型的 Evidence 和不可变 Source Revision。
- [ ] 人工评价 citation precision、citation completeness、conflict disclosure、knowledge-gap honesty、unsupported factual sentence rate 和 answer usefulness；逐句保存支持或不支持依据，不能仅检查是否存在引用标记。
- [ ] 每个事实性句子都有有效证据引用，或明确标记推断与知识缺口；未经 evidence ID validator 的输出不成为最终回答，缺失限制条件和引用不支持结论均记录为失败。
- [ ] 使用可追溯的来源更新或移除场景保留初次回答、原 Synthesis 快照、refresh Proposal 和后续回答，核实旧 Evidence 仍可定位、freshness 与影响原因可见，未审核的刷新不会改写旧知识。
- [ ] bundle fixture 覆盖同 revision 重叠、多来源同摘录、单来源问题、矛盾证据、表格截断、过期依赖、仅 Chunk 无 Evidence 和预算容不下冲突双方；检查实际输入引用、完整 quote、可见省略原因及人工理解到的限制。
- [ ] 报告区分自动 validator 结果、人工科学判断和可用性反馈，保留失败问题与未验证场景；用户认可的答案不能自动提升为临床或通用科研准确性声明。

# P40 稳定执行图谱增量展开与 Worker 布局

## Parent

[并行交付计划](../spec.md)；原任务 [#38](https://github.com/CaiZongyuan/knowmesh/issues/38)。

## What to build

用户连续展开局部图时保留已有位置和观察方向，新增节点在 Worker 中布局。快速切换筛选、root 或页面时，旧请求及迟到布局不能覆盖当前图；用规模 fixture 验证图谱上限内的可操作性。

## Acceptance criteria

- [ ] 双击展开一层前可查看预计新增规模，超过约定阈值先确认；明确区分预估与实际结果，并保留 Core 截断信息。
- [ ] ForceAtlas2 在 Worker 执行，增量加入节点不随机重排已有节点；坐标按 workspace ID 与 node ID 缓存，相机和临时位置仅留浏览器。
- [ ] 网络展开及 Worker 布局绑定 graph generation/request identity；切换 root、filters 或 workspace 后，迟到结果被丢弃，不覆盖当前选中项和图数据。
- [ ] 离开页面后释放 Worker、Sigma、订阅和事件资源；重复进入页面不累积后台计算、事件回调或重复图实例。
- [ ] 500 节点/1000 边 fixture 下，布局期间仍可选择、查看 Inspector、操作筛选和列表视图；记录参考机器、实际加载/交互结果与未达目标的瓶颈。
- [ ] 浏览器测试与画布检查覆盖增量坐标保留、连续展开、迟到响应/布局、切换 workspace、离开重入、桌面及移动视口；测试操控时序而非依赖随机等待。

## Blocked by

- [P39 局部图谱与证据浏览](P39.md)

## Scope and handoff

本票拥有已有图谱页面的增量展开、临时坐标和异步布局生命周期。前置输入是 P39 的有界 Graph 数据、稳定节点身份、generation、过滤状态和 Inspector；若预估展开规模需要额外读取，限定为既有 Graph 查询的只读扩展并同步契约。

共享热点是 Graph 页面状态、Worker 依赖及锁文件、布局缓存和浏览器规模 fixture；涉及契约扩展时协调 OpenAPI 再生成。该票不改变 Core 遍历语义或提高产品数据上限，也不把浏览器布局写回规范知识。验收报告交给后续 Web 发布与性能汇总。

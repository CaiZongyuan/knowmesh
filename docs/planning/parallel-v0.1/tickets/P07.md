# P07: 有界 Graph neighbors 与 subgraph

## Parent

[并行交付规格](../spec.md)；原任务 [#19](https://github.com/CaiZongyuan/knowmesh/issues/19)。

## What to build

用户从指定 Node 或受限 roots 集合查询局部图，明确区分 accepted typed Relations 与弱 mentions，结果包含完整的查询限制与可见截断信息。

## Acceptance criteria

- [ ] `graph.neighbors/subgraph` 提供 Core query/result DTO、registry、SQLite 查询与 CLI；输出 root/roots、nodes、edges、Schema display metadata 和实际 query limits。
- [ ] 支持 relation/mention/both、incoming/outgoing/both、predicate、Node type、lifecycle/evidence status 筛选；默认图不会把 mentions 当作 accepted Relations。
- [ ] BFS 默认 depth 1、最大 3；nodes/edges 上限有效，达到限制停止扩展并返回 truncated/reason，重复节点和循环不造成无限遍历。
- [ ] 排序、重复边处理和筛选语义确定；数据来自一致索引快照，默认同步和 `--no-sync` 准确披露 generation 与完整性。
- [ ] Relation edge 保留公共 Relation ID 及证据关联，mention edge 明确其来源；失效 root、非法 depth/limit 和不支持的过滤值返回 typed error。
- [ ] 真实 SQLite/CLI fixtures 覆盖有向循环、孤立节点、双向/平行边、弱边、过滤后边界和大图截断；重建后图语义一致。

## Blocked by

None (ready after approved shared baseline).

## Scope and handoff

Graph capability 拥有遍历/过滤/限制；复用现有 Relations、node mentions 和 Schema projections。向 P08 与前端交付稳定 edge 身份和 Graph DTO；共享热点是 read ports、registry、CLI、图查询预算。停止于可查询的局部图，P08 负责 paths/node.related；布局、社区算法及推荐分数不属于本票。

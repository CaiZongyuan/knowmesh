# P37 从 Web 安全添加和移除来源

## Parent

[并行交付计划](../spec.md)；原任务 [#34](https://github.com/CaiZongyuan/knowmesh/issues/34)、[#37](https://github.com/CaiZongyuan/knowmesh/issues/37)。

## What to build

用户通过文件上传或单页 URL 添加来源、为既有来源追加 revision，并预览和确认 soft-remove。将现有来源写入、同步和 P36 幂等能力接入 HTTP 与 Source 页面；页面提交失败后可安全重试同一请求。

## Acceptance criteria

- [ ] HTTP 只接受受限文件上传或允许的 URL，拒绝任意服务器本地路径；类型、大小、文本编码及实际内容校验失败时不创建来源或索引。
- [ ] URL 抓取沿用 Core 的 redirect、DNS、地址和来源策略；远程 HTTP 请求不能借用本地 CLI 的私网放行参数绕过 SSRF 限制。
- [ ] 添加新来源和向 source_id 追加 revision 均有真实 Web 操作；同 hash 返回既有 revision 且不隐式移动 head，新增 revision 后刷新正确来源详情与影响信息。
- [ ] soft-remove 先展示 dry-run 影响，显式确认后才执行；历史 revision 与 Evidence 仍可读取，未确认或未认证的请求不能改变规范文件。
- [ ] mutation 使用持久幂等键并复用 P36 结果；网络响应丢失后重试不重复导入或移除，输入改变复用旧键时展示明确冲突。
- [ ] 用户可显式调用 sync 并查看报告，HTTP 复用同名 Operation；成功写入后按 generation 失效受影响 Query，失败不伪造本地成功状态，所有调用通过已同步 OpenAPI 的生成客户端。
- [ ] HTTP 和浏览器测试覆盖上传、URL、追加 revision、预览/确认移除、重放、非法路径与权限失败；本票不启动 Compiler。

## Scope and handoff

本票拥有 Source 写入的 HTTP 与 Web 工作流。前置输入是 P35 读取导航和 P36 Core 幂等契约，以及既有来源抓取、校验、事务与 sync 操作。公共同步 Operation 使用共享基线已确认的名称，不另建同义业务入口。

共享热点是来源 Input 映射、认证防护、OpenAPI 快照、生成客户端、来源页面与缓存失效。限定上传传输需要的临时资源生命周期，不引入独立存储系统；复用已有边界策略而非重写网络抓取器。与 P42 协调 Source 页写入窗口，任务编译及 Run 控制留给后续票。

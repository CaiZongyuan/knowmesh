# P08: 可取证 Graph path 与 node.related

## Parent

[并行交付规格](../spec.md)；原任务 [#19](https://github.com/CaiZongyuan/knowmesh/issues/19)、[#31](https://github.com/CaiZongyuan/knowmesh/issues/31)。

## What to build

用户查询两节点间有界最短路径，并从 `node.related` 取得由已记录图关系解释的邻近节点；每条知识路径可以继续按 Relation ID 取证。

## Acceptance criteria

- [ ] `graph.path` 与 `node.related` 使用 Core DTO、Operation descriptors、SQLite 和 CLI；node.related 复用 P07 的图关系与边类型语义，返回关联原因和边 ID。
- [ ] Path 默认无权最短路径，direction 支持 respect/ignore；默认 max depth 4、max paths 3，最大值分别为 6 和 10，非法值提前拒绝。
- [ ] Predicate allow/deny 在遍历时生效；相同深度的路径按 edge evidence status、predicate、Node ID 稳定排序，循环和重复路径受到约束。
- [ ] Path edge 保留 accepted Relation ID；无路径返回空集合而非伪造连接，弱 mention 或推荐信号不冒充可取证 Relation。
- [ ] 输出包含实际限制、generation/完整性和适用截断信息；真实 fixtures 覆盖反向边、环、多条最短路径、允许/禁止条件、边界和重建一致性。
- [ ] `search --include-graph-paths` 复用同一有界查询，返回过滤后的真实路径分组及能力状态；测试默认不启用、显式启用、限制/截断、通道不可用和 cursor 一致性，替换既有固定 unavailable 行为。

## Scope and handoff

Graph capability 继续拥有路径算法，复用 P07 的查询边界、public edge identity 和读取事务；本票同时拥有 Search 路径分组的 Core/CLI 接入，P39 只消费其已验证结果。共享热点为 Graph query/result、Search 能力与分页、registry 和 CLI；与 P07 落地后的契约对齐。停止于图记录可解释的相关节点和路径；Source overlap、Adamic-Adar、推荐 edge kind、布局和图嵌入均属于后续决策。

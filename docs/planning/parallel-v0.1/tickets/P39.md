# P39 浏览局部图谱、路径与边证据

## Parent

[并行交付计划](../spec.md)；原任务 [#34](https://github.com/CaiZongyuan/knowmesh/issues/34)、[#38](https://github.com/CaiZongyuan/knowmesh/issues/38)。

## What to build

用户围绕指定 Node 查看有界局部图，筛选关系并寻找路径，再从节点或边进入知识与 Evidence Inspector。交付 Graph HTTP、生成客户端和首个可操作图谱页面，同时提供键盘可用的列表替代视图。

## Acceptance criteria

- [ ] neighbors/path/subgraph HTTP 请求映射到 P08 及其前置 Core，保留方向、过滤、范围上限、零路径和截断信息；OpenAPI 与生成客户端同步。
- [ ] 页面使用指定的 Graphology/Sigma 稳定版本呈现真实节点与边；Schema 控制类型样式，accepted/uncertain/conflicting 同时有颜色之外的状态表达。
- [ ] 用户可搜索并聚焦节点、选择局部 root、查看路径和筛选 node type/predicate/evidence status；搜索结果中的 Graph path 可直接载入图谱，结果为空或被截断时明确展示状态。
- [ ] 单击节点或边打开真实 Inspector，Relation 展示方向、qualifiers、状态与全部 Evidence；来源上下文导航复用已有读取能力。
- [ ] URL 可恢复 root、filters 和 selected id，不保存完整图；列表替代视图可以用键盘完成节点选择与证据阅读。
- [ ] 浏览器测试确认画布非空、节点/边交互、路径方向、筛选与列表视图；本票只验证有界功能，不宣称完成 500 节点/1000 边性能或增量布局稳定性。

## Blocked by

- [P08 Graph 路径与 related](P08.md)

## Scope and handoff

本票拥有有界图谱阅读和路径到证据的完整流程。前置输入是 P08 的 Graph DTO、方向/上限规则，以及 P34 的读取与 Inspector。初版可使用确定性初始位置验证渲染；展开确认、Worker 布局、坐标持久化和迟到结果由 P40 统一交付。

共享热点是 HTTP Graph 路由、OpenAPI、生成客户端、图谱依赖与锁文件、Inspector 和 URL 状态。新增依赖必须协调前端锁文件写入窗口。Graph 数据来自 Query，不另外建立持久知识缓存；布局请求所需稳定 node ID 与 generation 应明确交给 P40。

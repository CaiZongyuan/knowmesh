# P49 独立 Web 静态包与兼容性 manifest

## Parent

[并行实施规格](../spec.md)；原始需求 [#44](https://github.com/CaiZongyuan/knowmesh/issues/44)。

## What to build

将现有 Web 客户端独立构建为可下载解压的静态压缩包，携带版本、API 兼容范围、必需能力声明与 checksums。用户显式挂载这份候选包即可测试 Web 安装，后端无需重新打包。

## Acceptance criteria

- [ ] 独立生成 tar.gz 与 zip 候选包，解压后具有带版本的单一根目录，包含入口页面、hash assets、knowmesh-web.json 和可核验校验值。
- [ ] manifest 记录 format_version、web_version、api_contract_range 与 required_capabilities，兼容范围依据实际 API 合同和已测试版本，不以 Web 与后端版本相等代替兼容性判断。
- [ ] Web 打包不构建或包含后端 binary、数据库、workspace、模型密钥或 node_modules；后端 package、原生 artifact 和 npm 包内容保持独立。
- [ ] 解压候选包后通过 P46 的显式静态资源挂载与 P33 的客户端握手启动，实际验证入口、资源和当前已实现页面；错误 manifest 与不兼容能力组合产生明确失败。
- [ ] 可独立替换兼容 Web 包并重新握手；移除 Web 后普通 CLI 仍可用，包清单与安装过程不会改写规范知识或触发迁移。
- [ ] 提供独立下载、校验、解压、同源挂载和静态服务器反向代理的说明，说明中只声称已执行的候选包验证范围。

## Blocked by

- [P33 Web Shell 与生成客户端](P33.md)
- [P46 外部 Web 资源托管](P46.md)

## Scope and handoff

本票拥有 Web 候选静态包、manifest 与安装说明，复用已生成客户端和静态托管能力；版本与兼容元数据和 P33、P46、P50 协调。打包可以早于全部 UI 主流程完成；完整 Web E2E 与产品发布资格由 P54 判断，不以 Shell 成功启动代替。

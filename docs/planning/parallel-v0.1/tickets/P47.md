# P47 原生后端压缩包校验值与安装器

## Parent

[并行实施规格](../spec.md)；原始需求 [#43](https://github.com/CaiZongyuan/knowmesh/issues/43)。

## What to build

构建五个目标平台的独立后端候选压缩包、checksums 和 Shell/PowerShell 安装器。用户无需前端工具链、浏览器或数据库服务即可安装后端，并用已有 fixture 完成初始化、导入、检索和内嵌资源读取。

## Acceptance criteria

- [ ] 候选产物覆盖 macOS arm64/x86_64、Linux x86_64/arm64 和 Windows x86_64；每份记录版本、目标平台、构建来源和可核验 checksum。
- [ ] 后端 release build 在没有 Node.js/pnpm、Web 构建产物和源码 Skill 目录的运行验收环境中可安装运行；构建只需要其后端源码资源，打包不包含或下载 Web。
- [ ] 手动解压、Shell 与 PowerShell 安装流程可使用受控候选 artifact 验证；校验失败、不支持平台和下载失败明确报错，不执行未通过校验的程序。
- [ ] 三大 OS 的干净环境记录 init、source add、sync、search、skills list/read 的 headless smoke 结果；所用步骤均为此时已交付能力，失败与未运行平台明确列出。
- [ ] 可选向量能力不可用的平台仍能启动并公开 vector=false；安装说明给出目标平台要求、PATH、校验、升级及卸载方式。
- [ ] 安装器不修改或删除知识 workspace，也不安装额外服务；候选包支持内容清单检查，版本升级测试保留原有规范知识。
- [ ] 交付供 P48 与 P50 使用的稳定平台产物命名和校验输入，并明确这是打包基础设施验收，完整 compile/review/apply 与十分钟安装体验在 P54 使用最终候选版本复验。

## Blocked by

## Scope and handoff

本票拥有后端 artifact 与原生安装器，复用现有 Rust workspace、锁定依赖和后端 CI；构建清单、版本元数据和目标平台配置是共享编辑点。可在业务功能尚未全部交付时测试候选产物，P50 负责独立发布工作流，P54 负责最终完整性和安装验收。本票不创建生产 release。

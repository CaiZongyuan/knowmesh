# P45 同步外部编辑并安全切换 Server 索引连接

## Parent

[并行交付计划](../spec.md)；原任务 [#13](https://github.com/CaiZongyuan/knowmesh/issues/13)、[#14](https://github.com/CaiZongyuan/knowmesh/issues/14)。

## What to build

Server 运行期间，用户外部编辑规范文件后可从后续 API 读取看到同步结果；执行已有 rebuild 时，Server 协调读取连接排空、索引替换和重新打开。补齐 Server 场景的生命周期，保留已验证的 CLI fast sync/rebuild/doctor 行为。

## Acceptance criteria

- [ ] watcher 对规范文件增改删进行有界 debounce，并调用既有同步 Core；短时间事件合并不会遗漏最终文件内容，也不把运行时或临时资源误当规范知识。
- [ ] 外部有效编辑最终反映为新的实际 generation，后续 API 读取可见；格式错误、未完成事务或外部修改冲突返回明确诊断，不发布混合知识快照。
- [ ] Server 活跃时执行已有 rebuild 可协调停止新索引使用、排空已有读连接、完成原子替换并重新打开；返回服务后的读请求使用新索引。
- [ ] rebuild 失败、替换失败或连接重开失败时保留可恢复状态，不能假报成功或让旧连接无限服务过时结果；等待与 busy 有明确界限和 typed error。
- [ ] 同步、canonical write 和 rebuild 遵循同一 workspace 协调规则；HTTP 请求不直接拥有底层连接，已有事务恢复与 runtime 保留测试不退化。
- [ ] 集成测试覆盖活跃读取期间 rebuild、连续外部编辑、无效编辑、Server 重启及替换故障；记录三平台连接生命周期的实际验证结果。

## Blocked by

- [P32 API-only Server](P32.md)

## Scope and handoff

本票拥有 Server 的 watcher 与索引连接生命周期。前置输入是 P32 依赖组装/启停方式，以及共享基线已实现的 fast sync、原子 rebuild、workspace 锁和恢复协议。可使用 status 等既有 API 观察同步及索引切换，不要求 Web 或新增管理端点。

共享热点是 Server 组装、连接池与维护协调、同步入口、必要的跨进程约定、架构规则和依赖锁文件。与 P41 协调 Server 生命周期更改，但不把任务执行作为硬依赖。该票不重写已实现的 CLI rebuild，不自动执行数据迁移或丢弃 runtime；平台差异和失败后的可用恢复路径必须交接给发布验收。

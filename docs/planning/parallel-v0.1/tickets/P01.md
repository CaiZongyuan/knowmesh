# P01 真实材料溯源清单与导入检索基线

## Parent

[并行实施规格](../spec.md)；原始需求 [#42](https://github.com/CaiZongyuan/knowmesh/issues/42)。

## What to build

为 Virtual Cell dogfooding 建立可追溯的真实材料清单，用当前已实现的导入、同步与词法检索能力复现最小研究资料库。整理至少 20 个论文片段和 10 个真实研究问题作为待人工审核的标注候选，供后续 Compiler、检索和 Answer 评测共同使用。

## Acceptance criteria

- [ ] 每份材料记录原始来源、标题、作者或发布者、版本或获取日期、内容 hash、引用定位、版权或许可来源及允许的存储和分发方式；许可不明时保留定位与待核实状态。
- [ ] 可复用清单与受限原文明确区分；仅允许再分发的内容进入可分发 fixture，需要独立获取的材料记录获取前提和校验信息。
- [ ] 至少 20 个片段和 10 个问题候选具有稳定标识、原文定位与研究主题；所有未经人工核实的标注均显示未审核，模型生成答案不能充当 gold。
- [ ] 在干净的临时 workspace 中重现材料导入、同步、来源读取与中英文词法搜索，记录实际命令版本、输入清单 hash、结果及失败原因；无模型密钥也可执行这一基线。
- [ ] 基线输出可回到对应 Source Revision；重复执行保留相同原始内容身份，材料不可获取或内容变化时给出可定位的失败记录。
- [ ] 交付待审核清单与审核记录入口，明确后续评测仍须人工批准的 gold、相关性判断和事实支持判断；本票完成不代表科研准确性已通过。

## Blocked by

None after approved shared baseline.

## Scope and handoff

本票拥有材料清单、来源元数据与已有导入/词法检索基线；复用 Source Library 与现有 CLI 集成测试方式。共享输入的标识、版本和 hash 由本票统一维护，后续评测引用同一份材料，不各自复制来源事实。将候选交给 P51、P52、P53；人工科学标注与质量判定不按 easy 工作量估算，也不由本票代签。

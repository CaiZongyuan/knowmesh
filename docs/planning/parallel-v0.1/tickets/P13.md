# P13: 持久 Run 准入、幂等绑定与 get/list

## Parent

[并行交付规格](../spec.md)；原任务 [#28](https://github.com/CaiZongyuan/knowmesh/issues/28)。

## What to build

Core 在任何模型调用前持久化一个可重放任务，并把幂等 key 绑定到同一 Run。用户通过 `run get/list` 查看已有状态、输入身份和 output references，不会因读取触发执行或恢复。

## Acceptance criteria

- [ ] Admission 用例在 SQLite transaction 中保存 Run、完整可重放 Input DTO、sanitized digest、actor/surface、parent、budget 与依赖 identity；省略 revision 时在创建事务内固定 indexed current revision。
- [ ] 同 workspace/operation/key 原子绑定同一 Run；相同请求重试观察原 Run，不同输入拒绝；并发准入、提交失败和进程重开不会产生重复 Run 或在绑定前调用模型。
- [ ] 固定 prompt/Schema/Purpose/provider profile 等语义 hash，secret 只保留环境变量引用；敏感输入可重放而普通 diagnostics/log 不含原文或密钥。
- [ ] `run.get/list` 提供 Core DTO、descriptors、CLI，返回状态、attempt、stage/progress、control、usage/budget、output/error、owner_active 与当前可执行动作；list 为有界摘要。
- [ ] 列表计数/页采用一致 runtime 快照；cursor 绑定查询和 runtime 变化，不能以 canonical generation 代替；get/list 只提示失联，不把 running 写为 interrupted，也不自动执行 queued。
- [ ] 真实 SQLite/Core 准入集成测试与 CLI 读取 fixtures 覆盖显式/隐式 revision、同 key 并发、坏/跨 workspace cursor、损坏持久输入、rebuild runtime 保留和无模型调用。

## Blocked by

None (ready after approved shared baseline).

## Scope and handoff

Run runtime capability 拥有准入、读取和身份契约；复用已有 operation_runs、runtime copying、typed IDs 与幂等规则，不重做 Proposal 幂等。共享热点为 Run port/DTO、runtime tables、migration registry、Operation registry 和 CLI 组装；新增 runtime 表必须纳入重建保留。准入暂以真实 Core/SQLite 集成用例验收，公共 CLI 仅暴露 get/list；P15/P20 负责 compile/ask 提交，P16/P17 负责控制/恢复。停止于无执行副作用的持久任务。

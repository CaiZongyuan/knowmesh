# P51 人工 gold 支持的真实 Compiler 评测

## Parent

[并行实施规格](../spec.md)；原始需求 [#42](https://github.com/CaiZongyuan/knowmesh/issues/42)。

## What to build

基于溯源清单中的真实论文材料运行完整 Compiler，用至少 20 个经过人工审核的片段衡量抽取、定位、实体解析和冲突检测。报告真实模型成本、失败与人工判断，建立可复查的 Compiler release gate 证据。

## Acceptance criteria

- [ ] 实际评测使用至少 20 个可追溯论文片段，每个 gold 记录人工审核者、时间、版本、原文定位与判定；未审核候选、模型自动标签和虚构 fixture 不计入人工 gold 数量。
- [ ] 人工 gold 未批准、材料权限不满足或真实模型不可用时，独立标记评测外部前提未就绪；运行工具准备完成不代表本票质量验收完成。
- [ ] 运行完整前台 Compiler 并保留 Proposal、Run 和 Evidence 引用，记录材料 hash、代码版本、模型配置、prompt/schema 版本、请求/token 用量、实际或有依据估算的成本及失败重试；普通日志不泄露密钥或受限原文。
- [ ] 逐项报告 entity precision/recall、entity resolution accuracy、claim atomicity、relation type accuracy、evidence quote exactness、locator validity、unsupported assertion rate 与 duplicate/conflict detection，并保留判定依据。
- [ ] 所有自动生成且进入 Proposal 的 assertion 的 Evidence locator validity 达到 100%；不满足时报告失败与具体样本，不删除失败样本或降低门槛，过滤候选及其 recall 损失可见。
- [ ] 人工复核 Compiler 对原文的限制条件和科研含义，区分引用定位正确、抽取语义正确与领域事实成立；可重跑工具输出相同评测集合和明确版本差异。
- [ ] 报告链接真实失败案例与范围明确的后续修复需求；评测代码和已有 golden fixture 结果分别记录，不以 deterministic controller 测试代替真实模型质量。

## Scope and handoff

本票拥有 Compiler 评测工具、人工标注记录与运行报告，复用 P01 材料身份、P15 完整管线及 Evidence verifier。人工科学审核是单独的外部就绪条件，medium 分配只描述工程执行复杂度。模型、gold 或 prompt 变化需固定新版本；发现实现缺陷交给相应能力票或独立修复票，P54 汇总 gate 结果。
